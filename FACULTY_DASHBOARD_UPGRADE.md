# Faculty Dashboard Upgrade

Implemented workflow:

Dashboard → My Classes → Class → Assigned Subjects →
CIA 1 / CIA 2 / External / Assignment (5 marks) / Question Paper Upload.

## Changes
- Removed Faculty **Add Student** from the sidebar.
- Added **My Classes** as the main academic entry point.
- Classes are filtered by the active academic year and selected active semester.
- Opening a class shows only that faculty's assigned subjects.
- Each subject provides separate actions for CIA 1, CIA 2, External, Assignment /5 and Question Paper upload.
- Added dedicated Assignment /5 mark entry with save/update support.
- View / Edit Marks remains available for correction after entry.
- Question paper flow continues to use the existing OCR/extraction and question-wise mark schema.
- All new class/subject pages preserve the same Faculty Panel theme.
